How it works Install GitHub

Your org's dependencies, licenses, and container images. One dashboard.

bomscope scans every repository in your GitHub org, GitLab group, or Azure DevOps project and shows you what you're running on: end-of-life runtimes, risky base images, stale packages, copyleft exposure, and CVE counts — in one place you host yourself.

Get started View on GitHub
$ git clone https://github.com/bomscope-dev/bomscope.git && cd bomscope
$ docker compose up -d
$ open http://localhost:8000 # paste your token in Settings, done

Supply-chain intelligence, not another scanner

Scanners flood you with findings. bomscope answers the questions a platform team actually asks.

Who's exposed, ranked

Insights rank your whole org by what matters: EOL software, critical CVEs, risky and unpinned base images, stale dependencies, copyleft licenses. Every row links to the repos behind it.

Full dependency inventory, searchable

Every package across every repo — npm, pip, Maven, Go, and more via syft SBOMs. Search "who uses lodash" and get the answer in one query, with versions and staleness.

Base-image posture you can steer

Define your trusted registries (hardened-image vendors, your internal mirror) in Settings — saving triggers a background rescan, and adoption is measured and trended over time.

Incremental and quiet

Repos whose HEAD hasn't moved reuse prior results. The 10th scan costs about what the first one did. Scans run nightly by default from a built-in scheduler.

Your infra, your data, no keys to us

Two containers: the app and Postgres. The token you paste stays in your database, never leaves your network. No telemetry, no sign-up, no SaaS.

Batteries included

docker compose up -d is the whole install. Settings are configured in the browser — no .env editing, no YAML schema to learn, no operator to deploy.

Five minutes to a running dashboard

One compose stack. One token. One click.

01

Clone and start

Docker and Git are the only prerequisites. Postgres ride along in the same compose file.

git clone https://github.com/bomscope-dev/bomscope.git cd bomscope docker compose up -d
02

Connect your platform

Open http://localhost:8000, go to Settings, pick GitHub / GitLab / Azure DevOps, and paste a read-only token. Nothing to edit on disk.

03

Run your first scan

Hit "Run scan now" — or scope to a few repos first to pilot. Progress streams live in the Settings console. From then on, bomscope rescans on a schedule.

Automate if you want to

Everything the dashboard does is also a CLI and an API.

# one-shot scan from CI, results to Postgres docker compose --profile analyze run --rm analyzer \ -p github -s https://github.com -o your-org -O output/analysis.json # options --trusted-registries "cgr.dev,registry.example.com" # what counts as a blessed image --no-incremental # force full rescan --vulns --no-freshness # trade speed for depth either way
